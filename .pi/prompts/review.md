description: Сверить изменения с задачей
argument-hint: "<путь к задаче>"
---
Задача: $@
Если это путь к файлу, прочитай его.

Код не меняй. Только ревью.
1. Посмотри изменения: git status и git diff. Новые файлы, которых нет в diff, прочитай целиком.
2. Сопоставь изменения с каждым критерием задачи: выполнен, не выполнен, не видно из кода.
3. Проверь крайние случаи: пустой ввод, пробелы, регистр, сочетание условий, пустой результат.
4. Найди лишнее: изменения, которых задача не требовала.

Ответ раздели на две части:
- Подтверждено: проблемы, которые ты воспроизвёл или которые прямо видны в коде. Укажи файл и строку.
- Предположения: что стоит проверить, но ты не подтвердил.
