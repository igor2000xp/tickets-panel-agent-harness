# Панель обращений

Небольшое приложение на React + TypeScript (Vite). Показывает список обращений в поддержку. Данные локальные, бэкенда нет.

## Структура
- src/data/tickets.ts — тип Ticket и подписи статусов STATUS_LABELS
- src/data/tickets.json — демо-данные
- src/lib/ — чистая логика без React. У каждой функции рядом тест: имя.test.ts
- src/components/ — компоненты, которые только отображают данные
- src/App.tsx — состояние экрана и сборка компонентов
- src/styles.css — все стили
- tasks/ — постановки задач с критериями
- agent/ — отдельный учебный агент. К задачам приложения не относится, не читай и не меняй

## Команды
- npm test — тесты (vitest run)
- npm run typecheck — проверка типов (tsc --noEmit)
- npm run dev — dev-сервер. Не запускай: он уже открыт в отдельном терминале

## Правила
- Логику держи в src/lib в виде чистых функций. Компоненты только отображают.
- Тестируем только логику в src/lib. Компонентные тесты не нужны.
- Новые зависимости не добавляй.
- Для интерфейса используй готовые классы из src/styles.css: .toolbar, .field, .button, .empty. Новые стили добавляй только если без них не обойтись.
- Не меняй файлы в src/data, если задача этого не требует.
- Меняй только то, что нужно для задачи. Попутный рефакторинг не делай.
- Тексты интерфейса и названия тестов пиши на русском.

## Когда задача считается выполненной
1. Каждый критерий задачи покрыт тестом или проверен вручную. Укажи, какой как.
2. npm test и npm run typecheck выполнены в этой сессии и прошли.
3. В итоговом сообщении: изменённые файлы, выполненные команды с результатом, что не проверено.

Не пиши «готово», если команды не запускались.
