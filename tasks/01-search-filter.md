# Поиск и фильтр по статусу

Добавить над списком обращений поиск по заголовку и фильтр по статусу.

## Критерии
1. Поиск по заголовку без учёта регистра.
2. Пробелы в начале и в конце запроса игнорируются.
3. Поиск и статус работают вместе: в списке только то, что подходит под оба условия.
4. Статус «Все» не ограничивает список.
5. Если ничего не найдено, вместо списка видно сообщение «Ничего не найдено».
6. Счётчик рядом с заголовком показывает число найденных обращений.

## Ограничения
- Логика фильтрации — в src/lib/filterTickets.ts, с тестами на критерии 1–4.
